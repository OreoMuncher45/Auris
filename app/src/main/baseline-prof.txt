# Baseline profile: ahead-of-time compilation for the code a cold start, a
# first scroll and a first play run through. Without it that code starts every
# install interpreted and is JIT-compiled piece by piece, which is the
# first-launch, first-scroll and first-player-open jank a release build had.
#
# Wildcards rather than a recorded profile: recording one needs a
# macrobenchmark run on an API 33+ or rooted device. Every rule below is a
# superset of what a recorded journey would list for its package.
#
# AGP merges the profiles libraries ship inside their AARs with this file, so
# the libraries that already ship one are left to it rather than restated here:
# Compose runtime, foundation, ui and material3; Coil's core and compose-core;
# Haze; Navigation; Lifecycle; Activity. (Checked against the AARs this build
# resolves — each carries a baseline-prof.txt.)
#
# The app's rules match classes from every module in the APK, so the shared
# modules (:shared, :sharedUi) are covered by the same package rules as :app.
#
# H = hot, S = run during startup, P = run after startup. L…; = a class to
# load and initialise into the boot image ahead of first use.

# ---- Auris itself: app, shared data/playback layer, shared UI -----------------
# Includes the vendored backdrop engine (ui/components/backdrop) and the player.
HSPLcom/music/bitchord/**->**(**)**
Lcom/music/bitchord/**;

# The Discord rich-presence client (vendored Kizzy), in :shared.
HSPLcom/my/kizzy/**->**(**)**
Lcom/my/kizzy/**;

# The USB audio driver module.
HSPLcom/decent/usbaudio/**->**(**)**

# including the vendored FFmpeg decoder under androidx/media3/decoder/ffmpeg.
